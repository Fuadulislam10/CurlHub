# CurlHub

CurlHub is a learning-focused web recon tool that extracts publicly accessible
parameters, paths, endpoints, and direct links from a domain.

## Usage
python3 curlhub.py https://example.com

# **✅ Features**
 Crawl URLs & paths 
 
#  **Extract:**
Query parameters: (?id=1&user=admin)
Endpoints: (/api/v1/users)
Direct links (JS, CSS, images, PDFs)
Parse: HTML JavaScript files
 Uses: curl regex-based parsing
 
#  **Respects:**
Only public resources
No authentication bypass
No private/local files

## Disclaimer
Only use on domains you own or have permission to test.
